Embabel Agent Framework — Cheat Sheet

Embabel 1.0 learning demo · Print / PDF companion to docs/CHEATSHEET.md

Mental model

User/system input → Blackboard (typed)
                 → Planner picks next @Action
                 → Action: LLM / code / tools / subagents
                 → Return posts types → REPLAN
                 → @AchievesGoal return type → DONE

OODA: Observe blackboard → Orient conditions → Decide plan → Act

Annotations

AnnotationMeaning
@AgentSpring + agent; description for selection
@EmbabelComponentReusable actions, not a full agent
@ActionPlanner step; types drive GOAP
@AchievesGoalCompleting action finishes process
@ConditionBoolean fact (side-effect free)
@RequireNameMatchBind by name, not only type
@StateScope actions; enable loops
@Export(remote=true)Shell / MCP / A2A exposure
@LlmTool / @ToolCustom tool / domain tool (needs attach)

Blackboard rules

  • Latest of a type wins — unless named binding
  • Return new type = post effect
  • null / failed ifPossible → replan
  • Conditions called often → pure
  • State transitions hide prior states

LLM patterns

// Java
ai.withDefaultLlm().createObject(p, Story.class);
ai.withLlm(LlmOptions.withAutoLlm().withTemperature(0.7))
  .creating(Story.class).fromPrompt(p);
ai.withDefaultLlm().createObjectIfPossible(p, Person.class);
// Kotlin
context.ai().withDefaultLlm().createObject<Story>(p)
context.ai().withDefaultLlm().createObjectIfPossible<Person>(p)
fromForm<PersonProfile>("Fill this in")

Invocation

AgentInvocation.builder(agentPlatform)
  .options(ProcessOptions.DEFAULT.withVerbosity(Verbosity.DEFAULT.withShowPrompts(true)))
  .build(ReviewedStory.class)
  .invoke(new UserInput("..."));  // selects by goal return type

Debug first stops

  • First @Action entry
  • createObject / fromPrompt
  • Action return (blackboard post)
  • @Condition / planner choice
  • Goal @AchievesGoal

Don't forget

  • Source order ≠ execution order
  • @Tool needs withToolObject
  • High HITL cost = fallback
  • Supervisor needs action descriptions
  • StuckHandler ≠ incomplete model
