# Printable study materials

| File | Purpose |
|------|---------|
| [`embabel-cheatsheet.pdf`](embabel-cheatsheet.pdf) | Printable cheat sheet (generated) |
| [`cheatsheet.html`](cheatsheet.html) | Print-optimized HTML source |

## Regenerate the PDF

```bash
./scripts/generate-cheatsheet-pdf.sh
```

Requires Chrome/Chromium. Fallback: open `cheatsheet.html` in a browser → **Print → Save as PDF** (Letter, minimal margins, background graphics on).

Markdown source of truth for content: [`../CHEATSHEET.md`](../CHEATSHEET.md).
