# Cookbook 1.5 overview

This is a study series for Embabel Agent Framework 1.5.

The official Embabel Cookbook is an executable book. Every chapter has a matching
Java test. We take those twelve recipes and turn them into a learning track:
Java and Kotlin counterparts, guided unit tests, and short videos.

Part one is planner behavior: type chaining, conditions, stuck state, action cost,
repeat-until loops, and debugging.

Part two is the 1.5 AI APIs: typed object creation, nullable extraction, prompt
messages, thinking traces, streaming, and tool calls.

You can follow along offline. The tests use FakeOperationContext. When you want
live models, export an OpenAI or Anthropic key and run the Java or Kotlin shell.

The finished videos are meant to land in Memory OS so later agents can recall
how each 1.5 API works.
